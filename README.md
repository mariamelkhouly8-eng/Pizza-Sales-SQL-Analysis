# Pizza Sales SQL Analysis

# 📊 Project Overview
This project focuses on analyzing pizza sales data using SQL to uncover sales trends, customer ordering patterns, and product performance.
The analysis transforms raw sales data into meaningful business insights that can support decision-making related to products, pricing, sales performance,
and customer behavior.

# 🛠️ Tools & Technologies
- SQL
- SQL Server
- Data Aggregation
- Data Filtering
- Data Grouping & Sorting
- Calculated Fields
- SQL Views

# 🎯 Business Questions
# The analysis answers key business questions such as:
- What are the total sales and total number of orders?
- How many pizzas were sold?
- What is the average order value?
- What is the average number of pizzas per order?
- Which pizza categories generate the highest sales?
- Which pizza sizes are most popular?
- What are the daily sales and order trends?
- Which products contribute the most to overall sales?

# 🔍 SQL Techniques Used
# The project demonstrates practical use of:
- `SELECT`

- `GROUP BY`
- `ORDER BY`
- `SUM()`
- `COUNT()`
- `COUNT(DISTINCT)`
- `ROUND()`
- `CAST()`
- Calculated fields
- SQL Views

# 📈 Key Analysis Areas

# Sales Performance
Analysis of total revenue, order volume, and average order value.

 Product Performance
Comparison of pizza categories, sizes, and individual products based on sales and quantity.

# Order Analysis
Analysis of daily ordering patterns and the average number of pizzas per order.

# Business Insights
The analysis helps identify high-performing products, popular pizza sizes, and sales patterns that can support better business decisions.
